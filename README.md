Доработанная курсовая работа - приложение для инвентаризации.

Функционал приложения:
Поддержка нескольких списков объектов (например, под разные категории объектов или помещения).
Возможность создания, редактирования, удаления, объединения списков объектов, импорта и экспорта списков в форматах JSON, CSV.
Работа с инвентарём: добавление объекта, изменение данных, списание объекта.
Поиск объекта по инвентарному номеру или другим параметрам.
Импорт и экспорт базы данных целиком в форматах JSON, CSV.
Поддержка аутентификации и авторизации (три роли пользователей – обычный пользователь с правами на просмотр списков, сотрудник с правом отмечать наличие инвентаря, администратор с полным доступом).
Поддержка сериализации/десериализации состояния клиента и сервера при запуске/завершении работы.
Поддержка логирования.
